# The Aglomeration

Mod Java para Mindustry v154. Adiciona blocos de Zona que podem ser organizados em areas quadradas de 1x1 ate 8x8. Cada tamanho oferece construcoes com custos e tempo de construcao; desmontar devolve 75% dos recursos usados.

## Build 61

Arquivo de build recebido: `TheAglomeration.jar`. O JAR contém `mod.hjson`, classes Java compiladas e `sprites/frog.png`.

## Compilar
Requer JDK 17 e Gradle 8.7 ou compativel.

```sh
gradle clean jar
```

O JAR e gerado em `build/libs/`.
